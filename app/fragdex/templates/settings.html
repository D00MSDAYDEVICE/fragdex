Discord usernames

{% if dp.total %}{{ "{:,}".format(dp.named) }} of {{ "{:,}".format(dp.total) }} found{% endif %}

A Discord ID is only a number. With a bot token, the app looks up the username for each ID and shows it on the Players page, checking again every {{ cfg.DISCORD_REFRESH_DAYS }} days. Create an application at discord.com/developers/applications and copy the token from its Bot page. The bot doesn't need to join a server or have any permissions.

{% if fq.verified or fq.claimed %}{{ "{:,}".format(fq.verified) }} verified · {{ "{:,}".format(fq.claimed) }} claimed{% endif %}

Reads the Discord account each player linked to their Steam account from one or more FragQ servers, every {{ cfg.FRAGQ_SYNC_MINUTES }} minutes. Verified means the player proved the Steam account on a trusted FragQ server; claimed means nothing Fragdex can rely on proves it. On FragQ's Connectors page, press Create Fragdex connector, then add the FragQ address from that panel and the key here.
