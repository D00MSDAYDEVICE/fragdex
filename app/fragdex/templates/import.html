What gets imported

  • .fdx files — the desktop scanner's output (names and Steam IDs from many demos at once; demos already imported by either route are skipped), or a full-history Export .fdx from the Players page of any Fragdex server, including its notes and tags.
  • Demos (.dm_91) — every player name + Steam ID in the demo's configstrings, including players who join or rename mid-match. Dated by the match start time. Demos contain no IP addresses.
  • minqlx chat logs — connect lines like [2026-10-29 19:27:35] Name:76561197960287930:203.0.113.45 connected.
  • Server logs — lines with an info string (n\Name\…\st\7656…, \ip\…), or any line with exactly one Steam ID and one IP. Lines without a timestamp use the file's modified time.
  • Spreadsheets (.xlsx / .csv) — columns matched by header: Player Name, Steam ID, Aliases, IP Address, Date. Steam IDs stored as numbers (e.g. 7.65611980147868E+16) have lost digits and are skipped.
  • Re-importing the same file is detected and skipped; identical records are never duplicated.
