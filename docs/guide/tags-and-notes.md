# Tags and notes

Tags and notes record what *you* know about a player, alongside what the imported files say. Both need the **editor** role to change, and both are included in [.fdx exports](export.md) so they survive backups and moves between servers.

## Tags

Tags are short coloured labels such as *banned*, *cheater*, *friend*, *regular* or *clan: XYZ*.

**Apply tags** on a player's profile under **Tags**: tick the ones that apply and press **Save**. To create a new tag at the same time, type its name in **New tag…**.

**Manage tags** on the **Tags** page: create tags, rename them, change their colour and see how many players have each one. Deleting a tag removes it from every player; the players themselves are untouched.

**Filter by tag** on the Players page with the **All tags** drop-down. Combined with a search or the date filter, this answers questions like *which banned players were seen this month?*

## Notes

Each player has one free-text **Notes** field on their profile: bans, reports, demo timestamps, links to evidence, who added what. Press **Save notes** to store it.

Notes are searchable: anything typed in the Players search box also matches note text, so writing consistent keywords (for example `ban:`, `report:`) pays off later.

When a `.fdx` export is imported on another server, notes that differ from the existing ones are **appended**, never overwritten. Notes entered with [Add records manually](add-records.md) are appended too.
